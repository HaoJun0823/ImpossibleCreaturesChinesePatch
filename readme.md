初步汉化完成。
所有文本都存储在dll里，是.rc格式的资源文件，因此，使用ResourceHacker（https://www.angusj.com/）可以快速实现汉化。
rc文件夹是我提取过的和汉化好的。
语言根目录下的Text.dll里面有字体设置：

STRINGTABLE
LANGUAGE LANG_CHINESE, SUBLANG_CHINESE_SIMPLIFIED
{
  250, 	"normal \"Microsoft YaHei\" 24 32 40 0 134"
  251, 	"century14 \"Microsoft YaHei\" 12 16 40 0 134"
  252, 	"century16 \"Microsoft YaHei\" 12 16 40 0 134"
  253, 	"century18 \"Microsoft YaHei\" 12 16 40 0 134"
  254, 	"GillSans_18a \"Microsoft YaHei\" 12 16 40 0 134"
  255, 	"century14_chat \"Microsoft YaHei\" 12 16 40 0 134"

}

这里我设置成微软雅黑了，参照韩文的字体设置，保留后面的参数，134是GB2312（136是BIG5），40是字体大小，24和32不明，0应该是倾斜加粗控制，没有测试。
